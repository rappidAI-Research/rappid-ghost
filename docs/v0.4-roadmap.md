# Ghost v0.4: adaptive, but never permissive by inference

Status: development plan, not a release claim.

## Goal
Make Ghost easier to adopt across different agent projects without allowing project heuristics, prompts, or AI models to silently weaken isolation.

## Phase 1 (this branch)
- Optional `ghost doctor` diagnostic; zero mutation, zero auto-grants.
- Detect well-known project *markers* (not their contents) to identify probable agent and language workflows.
- Explain the active policy, supported runtime and likely integration blockers.
- Support text and versioned JSON output for CI/integration.
- Preserve `ghost init` + `ghost run <command>` as the minimal path.

## Phase 2: agent/runtime compatibility (not implemented)
- A strictly validated image/runtime contract for Python, Node.js and coding-agent binaries. Never use unpinned or ambient host executables.
- Agent-specific adapters with compatibility gates, reproducible isolation tests and safe credential brokering. No generic host-home mount.
- Support local-model endpoints by an explicitly authenticated and scoped broker; do not broadly exempt private IP ranges.
- Define security invariants before enabling a new network transport.

## Phase 3: company workflows (not implemented)
- Policy packs for coding, document processing and audited agent tasks, each requiring explicit approval.
- Framework-independent tool-call mediation and MCP gateway with stable typed contracts.
- Per-user/per-tenant permissions enforced by the host application, separate from Ghost's agent sandbox.
- Redacted event exports, CI evidence and independent adversarial review.

## Non-negotiable rules
1. A project hint never grants network, filesystem, model-server or tool privileges.
2. Invalid configuration remains invalid; no auto-repair or permissive fallback.
3. Don't claim Ghost can inspect model intent, arbitrary document reads or private application databases.
4. Keep sensitive customer data out of diagnostics and audit logs.
5. No claim of release-readiness without successful full Linux Docker gates, security review, and actual agent-integration tests.
