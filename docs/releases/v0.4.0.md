# Ghost v0.4.0 — explicit runtimes and advisory setup

This release combines explicit runtime compatibility with deterministic security
controls. Publication requires the exact-commit Go, image-vulnerability, Docker,
strict GhostBench and normal-user workflow gates.

## Implemented

- Advisory Doctor schema 2: descriptor-safe fixed-name project/framework/agent
  hints, host PATH presence, Docker capability diagnosis, explicit runtime and
  adapter catalog, read-only/network restrictions and actionable recommendations.
- Closed runtime catalog: default Alpine plus source-pinned Python 3.13.18 agent
  image; independent pinned security sidecars, inspected image-side behavior and
  immutable prepared agent image identity. No arbitrary image or host fallback.
- Pure Python entrypoint adapter, original argument boundaries and stdin/stdout;
  runnable offline example and production-path Docker tests.
- Explicit coding/document-processing/restricted validation profiles without
  automatic policy mutation or new network/filesystem privileges.
- Bounded no-follow/nonblocking config and approval reads, request/concurrency
  budgets, nested-mount exclusion and inspected Docker privilege boundaries.
- A 26th GhostBench scenario verifies Python confinement and ordered SHADOW
  network containment. Existing 25 scenarios are retained unchanged.
- Checksum-pinned runtime-image vulnerability gate for both source-catalog images; known CRITICAL findings, scanner errors and unsupported OS lifetime block release.
- Previously unreleased v0.3.1 CLI, recovery and Go build-security work is included.
  No v0.3.1 release is fabricated or required.

## Scope and limitations

Linux amd64 Docker Engine is the execution gate; Linux arm64 is build-only.
Python support is standard-library execution, not an LLM, model provider or blanket
framework certification. Claude Code, Codex CLI, Node.js runtimes, LangChain,
LangGraph, MCP mediation, local LLM access and application/tenant authorization
are not verified integrations. The tool/model broker is a concrete future contract,
not shipped functionality. Ghost supplies runtime controls, not privacy compliance
or complete protection against hostile code, prompt injection or container escape.
